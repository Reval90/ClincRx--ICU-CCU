# Medication Review Interface

## Overview

Interface for clinical pharmacist medication assessment and optimization.

## Medication List

Displays:

- Drug name
- Dose
- Route
- Frequency
- Indication
- Start date

## Clinical Review

Assessment:

- Appropriate indication
- Dose verification
- Renal adjustment
- Drug interactions
- Monitoring requirements

## Safety Alerts

Displays:

- High-risk medication warnings
- Interaction alerts
- Dose adjustment alerts
- Allergy alerts

## Pharmacist Actions

Functions:

- Approve medication
- Add recommendation
- Request modification
- Document intervention
