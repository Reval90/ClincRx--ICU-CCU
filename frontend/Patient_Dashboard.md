# Patient Dashboard

## Overview

Patient-centered dashboard for ICU/CCU clinical pharmacy review.

## Patient Header

Displays:

- Patient ID
- Age
- Gender
- Weight
- ICU Admission Date
- Primary Diagnosis

## Clinical Status

Displays:

- Hemodynamic status
- Respiratory status
- Organ function

## Medication Overview

Displays:

- Current medications
- High-alert medications
- Recent changes
- Drug interaction alerts

## Monitoring Section

Displays:

- Vital signs trends
- Laboratory values
- Therapeutic drug levels

## Pharmacist Actions

Functions:

- Add intervention
- Add recommendation
- Schedule follow-up
- Document clinical assessment
