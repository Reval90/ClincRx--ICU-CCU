# ClinRx-ICU-CCU Frontend

## Overview

User interface layer for ICU/CCU clinical pharmacy management system.

## Main Screens

## Patient Dashboard

Features:

- Patient information
- Vital signs
- Laboratory results
- Current medications

## Medication Review Screen

Features:

- Medication list
- Drug interactions
- Dose adjustment alerts

## Clinical Intervention Screen

Features:

- Pharmacist recommendations
- Documentation
- Follow-up

## Clinical Alerts Dashboard

Features:

- Critical alerts
- Monitoring reminders
- Safety warnings
