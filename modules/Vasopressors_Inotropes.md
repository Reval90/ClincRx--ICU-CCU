# Vasopressors & Inotropes Module

## Overview

Clinical decision support module for ICU hemodynamic management.

## Vasopressors

### Norepinephrine

- Class: Vasopressor
- Primary Use: Septic Shock
- Target: MAP ≥ 65 mmHg
- Monitoring:
  - Blood Pressure
  - MAP
  - Heart Rate
  - Peripheral perfusion

### Epinephrine

- Class: Vasopressor
- Primary Use:
  - Refractory Shock
  - Cardiac Arrest
- Monitoring:
  - Heart Rate
  - Arrhythmias
  - Lactate

### Vasopressin

- Class: Vasopressor
- Primary Use: Vasodilatory Shock
- Monitoring:
  - Blood Pressure
  - Electrolytes

## Inotropes

### Dobutamine

- Class: Inotrope
- Primary Use:
  - Low Cardiac Output States
  - Cardiogenic Shock
- Monitoring:
  - Heart Rate
  - Blood Pressure
  - Cardiac Function

### Milrinone

- Class: PDE3 Inhibitor
- Primary Use:
  - Heart Failure
  - Low Cardiac Output
- Monitoring:
  - Renal Function
  - Blood Pressure

## Clinical Pharmacist Responsibilities

- Dose verification
- Titration monitoring
- Adverse effect monitoring
- Drug compatibility review
- Documentation of interventions
