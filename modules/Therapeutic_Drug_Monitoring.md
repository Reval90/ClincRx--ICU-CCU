# Therapeutic Drug Monitoring (TDM) Module

## Overview

Clinical pharmacy module for optimizing medication therapy using drug concentration monitoring.

## Drugs Requiring Monitoring

### Vancomycin

- Monitoring:
  - AUC/MIC target
  - Serum concentrations
  - Renal function

### Aminoglycosides

Examples:
- Gentamicin
- Amikacin

Monitoring:
- Peak and trough levels
- Renal function
- Ototoxicity risk

### Digoxin

Monitoring:
- Serum digoxin level
- Renal function
- Electrolytes

## Clinical Pharmacist Responsibilities

- Interpretation of drug levels
- Dose adjustment recommendations
- Timing of blood sampling
- Monitoring toxicity
- Documentation of interventions
