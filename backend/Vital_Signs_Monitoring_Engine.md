# Vital Signs Monitoring Engine

## Overview

Component for monitoring ICU patient vital signs and generating clinical alerts.

## Input Data

- Blood Pressure
- Heart Rate
- Respiratory Rate
- SpO2
- Temperature
- MAP

## Monitoring Rules

## Hemodynamic Monitoring

Parameters:

- Blood Pressure
- MAP
- Heart Rate

Alerts:

- Hypotension
- Low MAP
- Tachycardia
- Bradycardia

## Respiratory Monitoring

Parameters:

- Respiratory Rate
- SpO2

Alerts:

- Oxygen desaturation
- Respiratory instability

## Temperature Monitoring

Alerts:

- Fever
- Hypothermia

## Clinical Output

- Alert level
- Clinical significance
- Recommended monitoring
- Pharmacist review
