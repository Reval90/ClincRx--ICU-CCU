# Patient Data Model

## Patient Entity

## Basic Information

Fields:

- Patient_ID
- Name
- Age
- Gender
- Weight
- Height

## Admission Information

Fields:

- Admission_Date
- ICU_Unit
- Primary_Diagnosis
- Secondary_Diagnosis

## Clinical Information

Fields:

- Vital Signs
- Laboratory Results
- Current Medications
- Clinical Notes

## Pharmacist Assessment

Fields:

- Drug Related Problems
- Interventions
- Recommendations
- Follow-up Plan
